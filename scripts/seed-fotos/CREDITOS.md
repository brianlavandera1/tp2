# Créditos de las fotos de artistas

Las fotos de esta carpeta las usa `npm run seed` para cargar los artistas de ejemplo. Provienen de [Wikimedia Commons](https://commons.wikimedia.org) y tienen licencias Creative Commons que permiten usarlas y redistribuirlas citando al autor y la licencia. Se usan reducidas a 900 px de ancho, sin otras modificaciones.

Los eventos del seed son **ficticios** y existen solo como datos de demostración del proyecto.
